# 02 · 视频生成：图生视频 / 文生视频 / 续接

## 1. 图生视频 —— `scripts\i2v.ps1`

```powershell
scripts\i2v.ps1 -Image x.png -Prompt "镜头缓慢推进，海浪拍打礁石" -Seconds 5
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `-Image` | 必填 | 起始帧 |
| `-Prompt` | 镜头缓慢推进… | **写"怎么动"，不写"有什么"** |
| `-Seconds` | 5 | 自动换算成 **4n+1 帧**（模型硬性要求） |
| `-Fps` | 24 | 帧率 |
| `-Steps` | 20 | 降到 12~15 明显更快 |
| `-Width/-Height` | 0（自动） | 0 = 按原图比例、上限约 0.55 MP、对齐 32 |

### 帧数约束（必须知道）

Wan 2.2 的 latent 结构要求帧数满足 **4n+1**：5, 9, 13, …, 121, 241。
写 `-Seconds 5` 时脚本自动算成 121 帧（24fps）。

### 提示词：写运动，不写画面

画面已经由输入图决定了，提示词只负责"怎么动"：

| ✅ 好 | ❌ 差 |
|---|---|
| 镜头缓慢向前推进 | 一片海滩有灯塔 |
| 轻微摇镜，画面右移 | 高清，8K，杰作 |
| 云层缓慢流动，光影移动 | （留空或重复画面描述） |
| 人物发丝被风吹动 | — |

## 2. 文生视频 —— `scripts\video.ps1 -Action t2v`

一条命令串两步：先出首帧，再让它动起来。

```powershell
scripts\video.ps1 -Action t2v -Prompt "黄昏的海岸灯塔" -Seconds 5 -Preset draft
```

## 3. 续接（做长片的关键）—— `scripts\extend.ps1`

```powershell
scripts\extend.ps1 -Video x.mp4 -Prompt "镜头继续推进" -Segments 2 -Seconds 5
```

原理：取上一段**最后一帧** → 当新段首帧 → 生成 → 与原片拼接。

**这是显存不够时做长视频的正确姿势**：每段按单段显存跑，想要 30 秒就循环 6 次。
段与段之间可能有轻微色调跳变，用同一个提示词 + 固定 seed 能明显减轻。

## 4. 预设档位

| 预设 | 含义 | 用途 |
|---|---|---|
| `draft` | 生成 832×480，不做后期 | 快速试提示词 |
| `fast` | Lanczos 1.5× + 插帧 2× | 30 秒内出可用片 |
| `final` | AI 超分 720p + 插帧 2× | 定稿 |

## 5. 实测基准（RTX 5090 Laptop 24GB）

| 任务 | 规格 | 耗时 | 显存 |
|---|---|---|---|
| 图生视频 | 736² / 121 帧 / 20 步 | 185 秒 | 约 16 GB |
| 文生视频 | 832×480 / 5 秒 / 20 步 | 125 秒 | 约 16 GB |
| 文生视频 | 1280×720 / 5 秒 / 20 步 | 362 秒 | 约 20 GB |
| 续接一段 | 3 秒 / 12 步 | 约 50 秒 | 同单段 |
| 端到端 `t2v + final` | 出图→视频→超分→插帧 | **5.9 分钟** | 峰值 16 GB |

**结论：草稿一律 832×480（2 分钟），定稿再超分**——比直接生成 720p 快 2.4 倍。

## 6. 坑

- **ComfyUI 必须先跑起来**：脚本会尝试用 `config.ps1` 的 `ComfyStartCmd` 启动，
  没配就提示你手动启动（不会静默卡住）。
- **模型名要匹配**：`config.ps1` 里的 `WanUnet/WanClip/WanVae` 必须是 ComfyUI 下拉框里
  显示的名字，写错会报 `Value not in list`。
- **CLIPLoader 的 `type` 必须是 `wan`**（写死脚本里，不用改）。
- **图片会被复制到 ComfyUI 的 input 目录**：ComfyUI 只认自己 input 里的文件。
- **生成结果落在 ComfyUI 的 output 目录**，脚本会自动搬到 `OutVideoDir` 并编号。
