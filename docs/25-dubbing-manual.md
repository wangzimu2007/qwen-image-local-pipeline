> 本地音频工作台 · 视频配音模块
> 版本：2026-10-28 · 适用：无声视频 / 无人声视频 / 带背景音乐视频 / 角色声音克隆

---

## 1. 这个功能能做什么

给一段视频**自动加上旁白配音**：

- 视频没有音轨 → 直接加一条旁白音轨
- 视频有背景音乐但没人声 → 可选保留原声（压到 25%）并混入旁白
- 用**提示词**描述想要的旁白，本地大模型会读画面、写旁白、定音色和语速
- 用**声音库角色**（如「阮梅」）做 F5 零样本克隆，让旁白像该角色
- 可选把旁白字幕烧录进画面

不做口型同步；换脸/口型请用其他工具。

## 2. 快速开始（3 分钟）

### 场景 A：无声视频 + 阮梅声音（最常用）

1. 打开「本地音频工作台」，进入 **视频配音** 页
2. 「视频」选择要配音的 mp4
3. 「提示词自动配音」填：

   ```
   用阮梅的声音，清冷平静地念一句湖景旁白
   ```

4. 「声音库角色」选 **崩坏星穹铁道 / 阮梅（hsr-ruanmei）**
5. 「配音引擎」保持 **自动**
6. 需要字幕就勾「把旁白字幕烧录到视频」
7. 点 **提示词自动配音**

运行日志里应出现：

```
音色库：崩坏星穹铁道 / 阮梅 -> C:\音频素材\崩坏星穹铁道\阮梅\参考-游戏原声.wav
配音引擎：F5 声音克隆
音画时长：音频 x.xxs / 视频 y.yys
视频完成：C:\Users\wangzimu\Desktop\视频\video-XXXX-promptdub-时间戳.mp4
```

### 场景 B：有背景音乐，想保留

在场景 A 基础上，勾选 **「保留原视频声音（25% 混音）」** 再运行。
原视频音轨会被压到 25%，与旁白混合；视频没有音轨时该选项自动忽略。

### 场景 C：自己写台词（精确控制内容）

1. 在「或手动输入台词」里填台词
2. 「参考人声」选一个 5~30 秒的参考音频（如阮梅的 `参考-游戏原声.wav`）
3. 点 **手动台词配音**

这条路径有参考音时也走 **F5 克隆**（失败才回退 Chatterbox）；没有参考音则用 Kokoro。

## 3. 界面字段说明

| 字段 | 作用 | 建议 |
|---|---|---|
| 视频 | 输入视频 | 支持 mp4/mov/mkv/webm/avi |
| 音调 | 变调半音（-12~+12） | 默认 0；克隆后做微调 |
| 共振峰 | 保留 / 跟随音调 | 默认「保留共振峰（自然）」 |
| 音色 | 原始 / 更明亮 / 更低沉 | 默认「原始音色」 |
| 配音引擎 | 选择 TTS 引擎 | **自动** 即可（见第 4 节） |
| 声音库角色 | 从 `voices.json` 选角色做克隆 | 用克隆时必选；与参考人声二选一 |
| 提示词 | 描述旁白内容和风格 | 越具体越好（见第 5 节） |
| 把旁白字幕烧录到视频 | 把 SRT 烧进画面 | 需要字幕时勾 |
| 保留原视频声音 | 原声 25% 与旁白混音 | 有 BGM/环境音且想保留时勾 |
| Kokoro 音色 | Kokoro 固定音色 | **用克隆时不用管** |
| 克隆语言 | Chatterbox/CosyVoice 用 | 保持 `zh` |
| 参考人声 | 自己提供参考 wav | 用声音库时**留空**；两者都填时参考人声优先 |

## 4. 引擎怎么选

| 引擎 | 说明 | 中文质量 | 速度 | 适用 |
|---|---|---|---|---|
| **自动** | 有参考音/声音库 → F5；没有 → Qwen 0.6B | 高 | 中 | **默认推荐** |
| **f5** | F5-TTS 零样本克隆 | 很好（ASR 字错率约 0） | 首次加载约 20 秒，之后快 | 角色克隆 |
| **qwen-fast** | Qwen3-TTS 0.6B CustomVoice | 好（CER 0~4.6%） | 约 30~90 秒/次 | 固定音色、不要克隆 |
| **qwen** | Qwen3-TTS 1.7B VoiceDesign | 最好（CER 3.1%） | 较慢 | 高质量固定音色 |
| **kokoro** | Kokoro 固定音色 | 差（CER 约 78%） | 很快 | 英文草稿、极速预览 |
| **chatterbox** | Chatterbox 参考克隆 | 一般（CER 约 59%） | 中 | F5 不可用时的回退 |
| **cosyvoice** | CosyVoice2 零样本 | 一般 | 中 | 兜底 |
| **seedvc / cosyvoice+seedvc** | 变声路线 | 取决于底音 | 慢 | 需要参考音 |

**自动引擎规则**：

- 选了「声音库角色」或「参考人声」→ **F5 克隆**
- 都没有 → **Qwen 0.6B**（不是 Kokoro）
- F5 失败 → 自动回退 Chatterbox

## 5. 提示词怎么写

推荐结构：**音色/人物 + 语气情绪 + 内容 + 时长/字幕要求**

示例：

```
用阮梅的声音，清冷平静地念一句湖景旁白
用低沉男声做纪录片旁白，讲这条老街的历史，语速稍慢
用活泼少女音介绍这款耳机，语气轻快，约 10 秒，字幕放底部
```

要点：

- 想用哪个角色，直接写「用阮梅的声音」，「声音库角色」再选一次更稳
- 写清「念什么内容」，不写的话模型会自己看画面编
- 旁白长度由代码按视频时长和引擎语速自动裁剪，**4 秒短片旁白会偏短**是正常的
- 想一字不差，用「手动台词配音」

## 6. 声音库管理

### 位置

```
C:\音频素材\voices.json
C:\音频素材\<游戏>\<角色>\参考音频.wav
```

### 档案字段

```json
{
  "id": "hsr-ruanmei",
  "game": "崩坏星穹铁道",
  "character": "阮梅",
  "aliases": ["阮·梅", "Ruan Mei", "ruanmei"],
  "reference": "C:\\音频素材\\崩坏星穹铁道\\阮梅\\参考-游戏原声.wav",
  "tags": ["女声", "清冷", "学者"]
}
```

### 加一个新角色

1. 准备 3~10 秒干净、无背景音乐的单人声 wav（48kHz 也可以）
2. 放到 `C:\音频素材\<游戏>\<角色>\`
3. 在 `voices.json` 的 `profiles` 数组里加一条（`reference` 写绝对路径，注意双反斜杠）
4. 回到工作台「视频配音」页点 **刷新**，下拉框即可选到

### 声音库 vs 参考人声

两者都填时 **参考人声优先**，声音库角色被忽略。用声音库时把参考人声留空。

## 7. 时长、字幕与封装规则

- 旁白长度 = 视频时长 × 引擎语速 × 1.35，超长会截到句号
- 音频明显长于视频时最多加速 **1.8 倍**；仍超长则按视频时长截断并加 150ms 淡出
- 字幕对齐基于**处理后的音频**，时间轴与画面一致
- 烧录字幕时自动复制到 ASCII 临时目录，中文路径不会失败
- 默认**替换**原音轨；勾「保留原视频声音」才混音
- 产物命名：
  - 视频：`桌面\视频\video-XXXX-promptdub-YYYYMMDD-HHMMSS.mp4`
  - 音频：`桌面\音频\audio-promptdub-...wav`
  - 字幕：`桌面\音频\文字稿\promptdub-...srt`

## 8. 命令行用法

### 直接调用

```powershell
D:\audio-tools\视频配音提示词.ps1 `
  -Video "C:\...\video.mp4" `
  -Prompt "用阮梅的声音，清冷平静地念一句湖景旁白" `
  -Voice 阮梅 `
  -Mode auto `
  -BurnSubtitles
```

常用参数：

| 参数 | 说明 |
|---|---|
| `-Video` | 视频路径（必填） |
| `-Prompt` | 提示词 |
| `-Mode prompt\|auto` | prompt 只生成提示词；auto 直接配音 |
| `-Voice` | 声音库角色（如 阮梅） |
| `-Reference` | 参考音频（与 -Voice 二选一，优先） |
| `-Engine` | auto/f5/qwen/qwen-fast/kokoro/chatterbox/cosyvoice/seedvc/... |
| `-Speaker` | Qwen CustomVoice 音色（如 uncle_fu） |
| `-BurnSubtitles` | 烧录字幕 |
| `-KeepOriginal` | 保留原声 25% 混音 |
| `-Pitch/-Formant/-Tone` | 音调/共振峰/音色后期 |

### 本地模型会话（走队列，自动等待）

```powershell
D:\qwen-image-2.1\提交作业.ps1 -Task videodub `
  -Video "C:\...\video.mp4" `
  -Prompt "用阮梅的声音念一段湖景旁白" `
  -Extra "Voice=阮梅;KeepOriginal" `
  -Wait
```

队列任务默认 `-Mode auto` 并烧字幕；`-Wait` 会等模型恢复后自动返回。

## 9. 常见问题

| 现象 | 原因/处理 |
|---|---|
| 成片没声音 | 运行日志看是否「视频封装失败」；确认视频时长>0、磁盘空间足够 |
| 克隆不像阮梅 | 参考音质量差或太短；换 5~10 秒干净人声；确认日志是「F5 声音克隆」而非 Chatterbox |
| 中文听不清 | 你可能用了 Kokoro；换自动/F5/qwen |
| 声音库选了但没生效 | 同时填了「参考人声」，参考人声优先；清空它 |
| 提示「声音库找不到」 | 角色名/别名不匹配，或 reference 路径失效；检查 `voices.json` |
| 字幕没烧上去 | 勾选「把旁白字幕烧录到视频」；中文路径已自动处理 |
| 第一次跑很慢 | F5/大模型冷加载；之后会快 |
| 改了代码界面没变化 | 关掉工作台重新打开（旧进程不会热更新） |
| 本地模型会话断线 | 直接跑脚本会卸载聊天模型；改用 `提交作业 -Task videodub -Wait` |
| 4 秒视频只有 2 秒旁白 | 旁白按视频时长裁剪，短片正常；想更长请用更长视频或手动台词 |

## 11. 已知限制

- 没有口型同步，只替换/添加音轨
- 旁白由本地 LLM 生成，质量取决于提示词和模型；重要内容建议手动台词
- 4 秒级短片旁白容易偏短（留白）
- 参考音质量决定克隆效果；有背景音乐/多人说话的参考音效果差
- F5 中文偶发多音字读错；可用手动台词换写法
- 克隆角色声音请仅用于个人/授权用途，注意版权与肖像/声音权益
