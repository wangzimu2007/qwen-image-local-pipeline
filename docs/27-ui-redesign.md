# 工作台界面改版（2026-10-28）

## 改了什么

| 项 | 旧 | 新 |
|---|---|---|
| 布局 | 顶部 12 页签 + 单列表单 | **左导航 + 中间工作区 + 右侧检查器** 三栏 |
| 导航 | 顶部 12 个页签，文字小、挤 | 左侧分组导航：常用 / 处理 / 工具 |
| 字号 | 10pt 基准 | **12pt 基准**，标题 30px，输入框/按钮同步放大 |
| 窗口 | 最小 900×650 | 最小 1060×720，默认更大；内容页自动滚动 |
| 页面标题 | 无 | 工作区顶部显示当前页名称（21px） |
| 右侧检查器 | 无 | 视频帧 / 波形 / 时长大小 / 播放 / 打开，可收起 |
| 视频配音页 | 字段平铺 | ① 视频与音色 / ② 引擎与声音库角色 / ③ 旁白内容 / ④ 输出选项 / ⑤ 手动台词 |
| 复选框 | 深色下几乎看不见 | 20px 方框，选中蓝色 |
| 输入框 | 偏小 | 高度和内边距加大，按钮加大 |
| 美化 | 旧深色 | 更深底色 + 卡片圆角 + 蓝色强调 + 更清晰的层级 |

## 操作变化

- 左侧点「视频配音 / 克隆 / TTS / 声音库」等切换页面
- 页面右侧有滚动条，内容多时上下滚动
- 「提示词自动配音」和「手动台词配音」现在分属 ③/⑤ 两段，不再混在一起
- 选择视频/参考音，或任务完成后，右侧自动显示画面/波形与媒体信息
- 顶部「队列 0」显示排队数量；「收起预览」可隐藏检查器
- 提示词框、日志框加高，方便看内容
- 运行中再点任务仍会进入队列（P2）

## 兼容性

- 功能逻辑未改，只改布局/样式/字号
- 旧配置（QSettings 里的路径记忆）继续有效
- 需要**关闭工作台重新打开**才能看到新界面
- 备份：`desktop_qt.py.bak-ui-20261028`（改动前的界面代码）
