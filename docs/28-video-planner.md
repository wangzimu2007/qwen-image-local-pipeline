# 视频生成智能规划（2026-10-28）

## 用途

生成前先判断“该怎么生成”，避免 10 秒单段爆显存、或该单段却用了续接。

```powershell
D:\qwen-image-2.1\视频规划.ps1 `
  -Prompt "手部极慢抽送，身体完全静止，镜头固定" `
  -Image "D:\...\src.jpg" -Seconds 10 -Fps 24
```

输出：场景判断、推荐模式、显存预估、可直接执行的命令。`-Json` 供程序读取。

## 判断规则

| 条件 | 推荐模式 |
|---|---|
| 时长 ≤5 秒 | **单段**，按请求 fps 生成 |
| 5~10 秒，固定镜头/慢动作 | **单段 12fps + FILM ×2**（120 帧，避免续接接缝） |
| 5~10 秒，镜头运动/复杂动作 | **2×5 秒续接**（末帧续接） |
| >10 秒，画面基本静止 | 同首帧多段 + 交叉淡化 |
| >10 秒，镜头/动作持续 | 5 秒一段续接 + 交叉淡化 |
| 需要声音 | 文本生视频 H3；图生视频生成后用音频模块/视频配音补声 |
| 显存不足 | 提示先走 `提交作业/显存门禁` 卸载聊天模型 |

显存估算按**推荐后的帧数**：基础 17500MB，每超过 120 帧加 60MB/帧。

## 场景识别关键词

- 固定/慢：固定、静止、不动、极慢、缓慢、微小、轻微、呼吸、眨眼、慢动作
- 镜头运动：推进、拉远、环绕、摇镜、旋转、跟随、运镜、平移、俯冲
- 复杂动作：跑、跳、打斗、转身、挥手、快速、奔跑、舞蹈、大幅、剧烈

## 实测

| 需求 | 推荐 |
|---|---|
| 10 秒，固定镜头、身体静止、手部极慢 | 单段 10s @12fps → FILM ×2 到 24fps |
| 10 秒，镜头推进 + 奔跑 | 2×5s 续接 |
| 显存只剩 300MB（聊天模型已加载） | 提示先卸载，走 `提交作业 -Wait` |
