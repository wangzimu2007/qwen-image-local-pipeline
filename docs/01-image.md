# 01 · 图片：文生图 / 图生图 / 指令编辑

## 1. 文生图 —— `scripts\t2i.ps1`

```powershell
scripts\t2i.ps1 -Prompt "黄昏的海岸悬崖，黑色礁石，白色灯塔，电影感"
scripts\t2i.ps1 -Prompt "..." -Width 1280 -Height 720 -Steps 8 -Seed 12345
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `-Prompt` | 必填 | 提示词。中英文都行，Qwen 系列中文理解很好 |
| `-Width/-Height` | 1024×1024 | 1024² 是甜点位；宽高都需为 8 的倍数 |
| `-Steps` | 8 | Turbo 模型 8 步足够；加步数收益很小 |
| `-Seed` | -1 | -1 表示随机 |
| `-Negative` | 空 | 反向提示词，一般留空也行 |

**关键：Turbo 模型必须用配套的 sigma 序列**（脚本已内置，也可在 `config.ps1` 里用 `T2ISigmas` 覆盖）：

```
1.0,0.978453,0.95418,0.926626,0.89508,0.845148,0.704534,0.414568,0.0
```

漏掉 `--sigmas` 会退化成普通采样，8 步出糊图——这是最常见的踩坑。

## 2. 图生图 —— `scripts\img2img.ps1`

```powershell
scripts\img2img.ps1 -Image x.png -Prompt "同一场景，改成油画风格" -Strength 0.85
```

| 强度 | 效果（实测于 Qwen-Image 2.1 Turbo） |
|---|---|
| 0.40 ~ 0.55 | 几乎不变，只微调质感/光线 |
| 0.55 ~ 0.70 | 改局部元素（换天空、换色调），构图保留 |
| **0.85（推荐）** | **整体重绘，构图仍大致保留** |
| 0.90 ~ 1.0 | 明显脱离原图，只借个大意 |

提示词写法：**写"目标画面"，不是写"要改什么"**。

- ✅「同一场景，改成水彩画，柔和笔触」
- ❌「把这棵树改成红色」（这是编辑的写法，见下）

## 3. 指令编辑 —— `scripts\edit.ps1`

```powershell
scripts\edit.ps1 -Image x.png -Prompt "把天空换成夕阳"
scripts\edit.ps1 -Image x.png -Prompt "去掉右边那个人"
```

特点：**只改你说的那一处，其余保持不动**。代价是慢（约 3 分钟/张）。

提示词原则：

1. **一次只改一件事**（同时改两处容易互相干扰）
2. **点名位置**：「左边」「天空」「衬衫」「背景」
3. 用陈述句，不用"请帮我"

| 场景 | 推荐写法 |
|---|---|
| 换背景 | 「把背景换成雪山」 |
| 改颜色 | 「把车漆改成哑光黑」 |
| 加/删元素 | 「加一只趴在窗台上的猫」/「去掉电线」 |
| 改光线 | 「改成傍晚逆光，暖色调」 |
| 改风格 | 「整体改成吉卜力动画风格」 |

## 4. 两个脚本怎么选

| 需求 | 用哪个 | 耗时 |
|---|---|---|
| 换风格 / 换色调 / 大改 | `img2img` | 20~25 秒 |
| 精准改一处、其余不动 | `edit` | 180~190 秒 |
| 只是想要一张新图 | `t2i` | 15 秒 |

## 5. 实测基准（RTX 5090 Laptop 24GB）

| 任务 | 分辨率 | 耗时 | 显存 |
|---|---|---|---|
| t2i | 1024² | 15 秒 | 约 15 GB |
| img2img | 1024² | 20~25 秒 | 约 15 GB |
| edit | 1024² | 180~190 秒 | 约 18 GB |

## 6. 坑

- **VAE 别混**：文生图用 `qwen_image_2.1_vae_bf16`，指令编辑用 `qwen_image_vae`（v1 版），
  两者不通用，用错会出现偏色/糊。
- **zero_cond_t**：2511 编辑必须开，否则画质明显退化。脚本已按三种参数形式自动回退尝试。
- **显存**：编辑要 17 GB 以上，跑之前先关掉占显存的聊天模型。
- **尺寸**：宽高建议 768~1280，超过 1536 显存和时间都不划算（要更大用 `img-upscale.ps1`）。
