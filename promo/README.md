## 封面设计要点（v0.2.0）

- 背景用**真实成片帧**（不是素材图），压暗 + 3px 模糊保证文字可读
- 主标题 6 个字：「一条命令出片」，其中「出片」走高亮色
- 副标题：`文生图 → 视频 → 超分 1664×896 → 48fps`
- 三个数据徽章：**5.9 分钟 / 1664×896 / 13 个脚本**（时间、能力、体量）
- 缩放后仍可读：B 站缩略图尺寸下标题依然清晰

## 内容口径（写稿时遵守）

1. 这是**流程整合**，不是新模型 —— 不写"最强/第一"
2. 速度一律标"RTX 5090 Laptop 24GB 实测"，其它显卡不给承诺
3. FlashVSR+ 的显存代价（23.3 GB）必须写出来，避免读者在小卡上撞墙
4. 模型许可证以各自模型卡为准，权重不由本仓库分发

## 重新生成
