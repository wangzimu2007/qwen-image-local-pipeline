## 内容

- **基线与显存预算**：24 GB 卡上各任务峰值，以及为什么"生成"和"本地聊天"不能同时跑
- **引擎与端口**：sd.cpp / 三套 ComfyUI / SeedVR2 CLI 的端口占用与三条互斥规则
  - 含**判断引擎身份的方法**（查 `/object_info/UNETLoader` 的模型列表，而不是只看端口）
- **模型清单**：按出图 / 视频分类的体积与来源提示；硬链接复用技巧
- **磁盘规划**：模型、引擎、输出、临时文件分别放哪
- **依赖与版本**：Blackwell 需要 cu128/cu130；补依赖必须 `--no-deps`
- **时间预算**：十几项实测耗时（含"恢复本地聊天模型"的 1~3 分钟）
- **复现检查清单**：模型齐 / 端口空 / 显存够 / 配置对 / 编码对 / 语法过
- **故障索引**：`value_not_in_list`、全黑画面、OOM、BOM 缺失等对应的排查方向
